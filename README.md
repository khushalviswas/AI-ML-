# AI-ML Learning Repository
A collection of Jupyter notebooks for learning Machine Learning and Artificial Intelligence concepts.

## About
This repository contains hands-on Machine Learning and AI notebooks created during my B.Tech studies and training programs. 
It focuses on understanding concepts through implementation.

## Topics Covered

- Feature Engineering
- Data Preprocessing
- Linear Regression
- KNN Classification
- Neural Networks
- Clustering
- Dimensionality Reduction (t-SNE)

## Repository Structure

AIML_Module_01/   → Basics of ML  
AIML_Module_02/   → Visualization & t-SNE  
AIML_Module_03/   → Classification  
AIML_Module_06/   → Neural Networks

## Technologies Used

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
  
## How to Run

1. Clone the repository
2. Install required libraries
3. Open Jupyter Notebook
4. Run any .ipynb file
